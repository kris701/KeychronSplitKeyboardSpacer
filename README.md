# KeychronSplitKeyboardSpacer
This is a small project to make some nice spacers for my split KeyChron Q11 keyboard.
I found it somewhat annoying that the keyboard pieces could get out of alignment slowly over time, and it would take me a while to realize it.
So i designed a spacer, that sort of locks the two keyboard pieces in a static position.
There are two versions, a full one and one with a gap in it.
The one with the gap in between is meant for you to have a mouse in between.
